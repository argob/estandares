Usa esta plantilla para pedirle a una IA que revise un servicio, contenido, API, flujo o componente.

```md
Actúa como asistente especializado en servicios digitales públicos.

Necesito que revises:

- Tipo de pieza:
- URL, archivo o descripción:
- Público principal:
- Tarea que debe poder hacer la persona:
- Canal:
- Restricciones conocidas:

Usa estos criterios:

- Necesidad ciudadana.
- Lenguaje claro.
- Accesibilidad.
- Seguridad y privacidad.
- Continuidad operativa y recuperación ante incidentes, cuando corresponda.
- Consistencia entre canales.
- Documentación y mantenibilidad.
- Sustento normativo cuando corresponda.

Devolve:

1. Resumen.
2. Hallazgos priorizados por severidad.
3. Evidencia concreta.
4. Impacto para la persona usuaria o el organismo.
5. Recomendación accionable.
6. Supuestos y validaciones necesarias.
```
